This guide explains how to run a TEE-enabled node that provides DHC services.

## Download the Deployment Scripts

```shell
git clone https://github.com/deepslabs/deeps-mining-scripts.git
cd deeps-mining-scripts
```

<Callout type="warn">
Before continuing, confirm that the CPU supports Intel SGX. See Intel's [SGX support guide](https://www.intel.com/content/www/us/en/support/articles/000028173/processors.html) for details.
</Callout>

## Configuration

Change to the `configs` directory and review the configuration before starting the services. Most values can retain their defaults, but you must configure the following field:

* `keyring.toml` → `identity`: The DeepS account that owns the device and submits transactions for device registration, activation, and reward collection.

## Create an Identity Account

Run the script:

```shell
docker run -it --rm deeps/deeps-node:release identity generate
```

Example output:

```shell
Secret seed:      0x71235e1458ce9d140c8b8ded28ccc1e32e62c340aef51a65e1350a387dbe08a6
Public key (hex): 0x0248e7f02dcc9f7061a090b67dede93d7381847e94955aee7996603d2225e9f77e
Account ID:       0x34a5572cb21d34354e3091564d5edc7b791e9d5f
```

Fund the generated account with enough testnet `tDPS` to register and activate the device and to pay transaction fees. Obtain testnet tokens only through an official DeepS testnet channel.

## General Commands

Manage the mining services with Docker Compose.

#### Start Mining

```shell
docker-compose up -d
```

#### Check Status

```shell
docker-compose logs
```

#### Stop Mining

```shell
docker-compose down
```

### Update Images

```shell
docker-compose pull
docker-compose up -d
```
