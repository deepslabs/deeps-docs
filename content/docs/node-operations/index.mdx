DeepS supports two node paths: **DeepS Chain nodes** maintain the blockchain network, while **DHC nodes** use trusted execution environments (TEEs) to provide secure services. Choose the path that matches the role you want to operate.

Before deploying a node, review the hardware requirements and confirm that your system meets the requirements for the selected node type.
