## Microsoft Azure

**Purchase Links:**

[https://azure.microsoft.com/](https://azure.microsoft.com/)

**Buyer's Guide:**

The DCsv3 and DCdsv3 VM series support Intel® SGX2.

[Create Intel SGX VM in the Azure portal](https://learn.microsoft.com/en-us/azure/confidential-computing/quick-create-portal)

**Configuration Reference:**

- Billing option: **Yearly or monthly; usage-based billing**
- Region: **East US 2**
- Instance: **DCsv3/DCdsv3 (8 vCPUs, 64 GB RAM)**
- Image: **Ubuntu Server 24.04 LTS, x64 Gen2**
- System disk: **512 GiB Premium SSD**
- Public IP address: **Assign a public IPv4 address**
- Bandwidth: **20 Mbps**
- Authentication type: **Password**

**Reference quote:**

8 vCPUs and 64 GB RAM: \$730.13/month or \$0.9040/hour, plus \$0.13/GB.
