---
title: Local LAN Configuration for SGX
description: How to configure a local LAN PCCS service for SGX
---

To use SGX within a local network, deploy a Provisioning Certificate Caching Service (PCCS) and configure every local DHC node to use it. Set `pccs_url` in each node's `sgx_default_qcnl.conf` file. For example, if PCCS runs on `host1`, use `"pccs_url": "https://host1:8081/sgx/certification/v4/"`.

Follow the steps below to configure the service.

### Applying for an Intel API Key

Obtain an Intel API key for the SGX provisioning services used by PCCS.

**Steps:**

1. **Create an Intel Developer Zone Account:** If you don't already have one, create an account on the Intel Developer Zone website.
2. **Navigate to the Intel API Key Management Page:** Once logged in, go to the Intel API Key Management page.
3. **Select the "Intel SGX SDK" Product:** Choose the "Intel SGX SDK" product from the list of available products.
4. **Provide Required Information:** Fill out the requested information, including your name, organization, and project details.
5. **Submit the Request:** Review the information you've provided and submit the request. Intel will evaluate your request and notify you of the outcome.

[Intel API Portal](https://api.portal.trustedservices.intel.com/products)

## Install a Local PCCS Instance

```bash
# Ubuntu 18.04:
curl -fsSL https://download.01.org/intel-sgx/sgx_repo/ubuntu/intel-sgx-deb.key | sudo apt-key add -
sudo add-apt-repository "deb [arch=amd64] https://download.01.org/intel-sgx/sgx_repo/ubuntu $(lsb_release -cs) main"
sudo curl -sL https://deb.nodesource.com/setup_16.x | sudo bash -
sudo apt-get install -y nodejs
sudo apt install cracklib-runtime -y
sudo apt-get install sgx-dcap-pccs libsgx-dcap-default-qpl
systemctl status pccs

# Ubuntu 24.04:
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential curl wget openssl libssl-dev pkg-config
sudo echo 'deb [arch=amd64] https://download.01.org/intel-sgx/sgx_repo/ubuntu focal main' | sudo tee /etc/apt/sources.list.d/intel-sgx.list
curl -fsSL https://download.01.org/intel-sgx/sgx_repo/ubuntu/intel-sgx-deb.key | sudo apt-key add -
sudo apt update
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs=20.11.1-1nodesource1
sudo apt install cracklib-runtime -y
sudo apt install -y sgx-dcap-pccs libsgx-dcap-default-qpl
systemctl status pccs
```

During installation, enter the Intel API key and create a strong, unique PCCS password.

Accept the default values for any remaining settings unless your network requires different values.

If the installer rejects the password as too weak, restart the installation and provide a stronger password.

If PCCS does not start successfully after installation, register the platform by following these steps.

### Register the Platform

**Step 1.** Install the register tool for SGX:

```bash
sudo apt install sgx-pck-id-retrieval-tool
```

**Step 2.** Modify the configuration file:

```bash
cat /opt/intel/sgx-pck-id-retrieval-tool/network_setting.conf
```

Set `PCCS_URL=https://localhost:8081/sgx/certification/v4/platforms`

**Step 3.** Use the PCK ID Retrieval Tool:

```bash
PCKIDRetrievalTool
```

```bash
systemctl status pccs
```

**Step 4.** Enable the SGX function.

If the error message persists, you may need to reseat the motherboard battery, reset the machine's BIOS, and re-enable the SGX feature.

**Step 5.** Run the PCK ID Retrieval Tool.

Repeat the command only if it reports that registration has not completed.

**Step 6.** Start the DHC processes.

After SGX registration succeeds, start the DHC processes. If the first attempt fails because cached collateral is not yet available, review the PCCS and DHC logs before retrying.
