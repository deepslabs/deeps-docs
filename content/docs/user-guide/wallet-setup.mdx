---
title: Wallet Setup
description: How to set up a wallet to interact with DeepS
---

To interact with DeepS and manage DPS tokens, configure an EVM-compatible wallet by following the steps below.

## Install a Wallet

Install one of the following browser extensions or mobile apps:

* MetaMask: [https://metamask.io/download](https://metamask.io/download/)
* OKX: [https://www.okx.com/download](https://www.okx.com/download/)
* Bitget: [https://web3.bitget.com/en/wallet-download](https://web3.bitget.com/en/wallet-download/)
* TP: [https://www.tokenpocket.pro/en/download/app](https://www.tokenpocket.pro/en/download/app)

## Import or Create an Account

Import an existing EVM account or create a new account for managing assets on DeepS. Store the recovery phrase securely and never share it.

## Configure the Network

Add the DeepS [network details](/docs/technical-reference/network-configuration), including the RPC endpoint, chain ID, and currency symbol, to your wallet.
