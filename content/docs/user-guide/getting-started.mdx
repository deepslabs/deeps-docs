Welcome to DeepS. Use the resources below to configure your wallet, connect to the network, and participate in node operations.

## Network and Wallet Setup

Start with the network configuration and wallet setup:

1. [**Network Configuration**](/docs/develop-guide/network-configuration): Review the chain settings required to connect to DeepS.
2. [**Wallet Setup**](/docs/develop-guide/wallet-setup): Configure an EVM-compatible wallet, such as MetaMask, to manage DPS tokens on DeepS.

## Node Operations

1. [**Hardware Requirements**](/docs/develop-guide/hardware/recommend-list): Review the recommended hardware for validator and DHC nodes.
2. [**DHC Node Maintenance**](/docs/user-guide/maintaining): Install, configure, and maintain the DHC node service.
3. [**DHC Farming**](/docs/user-guide/farming): Run or join a DHC node and manage your participation.
