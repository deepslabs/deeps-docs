DeepS Chain is built with the Polkadot Substrate framework and uses the **Nominated Proof-of-Stake (NPoS)** consensus mechanism.

Nominators and validators are the two primary roles in an NPoS network. Nominators back validators they consider reliable. Selected validators produce and finalize blocks, validate transactions, and earn rewards for helping secure the network.

Follow the [Node Operators](/docs/develop-guide/testnet/chain/node-operators) guide to run a DeepS Chain node. After the node is synchronized, follow the [Validators](/docs/develop-guide/testnet/chain/validators) guide to participate in consensus.
