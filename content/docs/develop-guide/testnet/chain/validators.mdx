title: Validators
description: How to become a validator on the DeepS Chain
---

Before continuing, start and synchronize a node by following the [Node Operators](/docs/develop-guide/testnet/chain/node-operators) guide.

Run `docker ps -a` and locate the DeepS node container ID shown in the `CONTAINER ID` column. Use this value as `<CONTAINER_ID>` below.

## Generate Session Keys

To become a validator, generate [session keys](https://wiki.polkadot.network/docs/learn-cryptography#session-keys) on the node and associate them with your validator account.

Enter the running container:

```shell
docker exec -it <CONTAINER_ID> bash
```

Generate the session keys:

```shell
curl -X POST http://127.0.0.1:9944 -H "Content-type: application/json" -d '{"id":1,"jsonrpc":"2.0","method":"author_rotateKeys","params":[]}'
```

Your result should resemble this sample:

```shell
{"jsonrpc":"2.0","result":"0x963d40e26c1d69acf3f75f96cd7782576382713b650d2ea81f5c8dbeb3797e1f17df3a8ab0d3a2dc3218972fdebe47a4463523ae1bbc0a6c91f3b33ace76c0eb","id":1}
```

<Callout>
Store the returned public-key set securely. You will need it when registering the validator.
</Callout>

## Prepare Testnet DPS

Ensure that the controller account in your EVM wallet has enough `tDPS` to meet the minimum validator bond and pay transaction fees. Obtain testnet tokens only through an official DeepS testnet channel.

## Set Validator

Open the [Validator Control Panel](https://test-validators.deeps.fi/), go to the node section, and select **To Be Validator**. If the account is already a nominator, stop nominating before registering as a validator.

Configure the commission, third-party nomination policy, and session keys:

* **Commission**: The percentage of the reward received by the validator when the reward is distributed. If the rewards are the same, the lower the commission means that the nominators will receive more rewards.
* **Allow third parties to join**: Determines whether other accounts can nominate the validator.
* **RotateKey**: Binds the validator account to the node by using the session keys generated in the previous step.
* **Pledge amount and reward destination**:
  * **Continue Pledge**: Continue to pledge funds to the account when claiming the reward.
  * **Direct Benefit**: Transfer rewards to the spendable account instead of bonding them.

Submit the validator-registration transaction and wait for a subsequent epoch. Once selected for the active validator set, the node must remain online and participate in block production. Failure to do so may result in a penalty and loss of part of the bonded stake.
